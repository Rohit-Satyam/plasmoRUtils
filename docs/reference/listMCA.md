# List data sets in MCA

This function lists all the datasets available on Malaria Cell Atlas
Database.

## Usage

``` r
listMCA()
```

## Value

df A dataframe listing all the datasets available on MCA and URls that
can be used with `easyMCA` function.

## Examples

``` r
if (FALSE) { # \dontrun{
  df <- listMCA()
} # }
```
