## Search functions

These functions provides CLI access to various databases

- [`searchApicoTFdb()`](https://rohit-satyam.github.io/plasmoRUtils/reference/searchApicoTFdb.md)
  : Fetch data from ApicoTFdb
- [`searchHP()`](https://rohit-satyam.github.io/plasmoRUtils/reference/searchHP.md)
  : Fetch Protein-protein interaction for given gene IDs from Hit
  Predict database
- [`searchIpDb()`](https://rohit-satyam.github.io/plasmoRUtils/reference/searchIpDb.md)
  : Fetch orthologs from InParanoiDb
- [`searchKipho()`](https://rohit-satyam.github.io/plasmoRUtils/reference/searchKipho.md)
  : Fetch Kinases and Phosphatases from Kipho Database
- [`searchMidb()`](https://rohit-satyam.github.io/plasmoRUtils/reference/searchMidb.md)
  : Fetch Minor intron tables from MiDB
- [`searchMiip()`](https://rohit-satyam.github.io/plasmoRUtils/reference/searchMiip.md)
  : Fetch Protein-Protein interactions from MIIP database
- [`searchPhPl()`](https://rohit-satyam.github.io/plasmoRUtils/reference/searchPhPl.md)
  : Fetch data tables from PhenoPlasm database
- [`searchPM()`](https://rohit-satyam.github.io/plasmoRUtils/reference/searchPM.md)
  : Fetch articles from PubMed database
- [`searchRS()`](https://rohit-satyam.github.io/plasmoRUtils/reference/searchRS.md)
  : Fetch articles from Research Square database
- [`searchTedConsensus()`](https://rohit-satyam.github.io/plasmoRUtils/reference/searchTedConsensus.md)
  : Fetch protein domains from TED database

## Fetching tables from databases

These functions helps users fetch annotations and data in form of tables
from various databases.

- [`getEffLen()`](https://rohit-satyam.github.io/plasmoRUtils/reference/getEffLen.md)
  : Get effective gene lengths form TPM calculation
- [`getMpmp()`](https://rohit-satyam.github.io/plasmoRUtils/reference/getMpmp.md)
  : Quickly fetch data from MPMP database
- [`getpairedOrthologs()`](https://rohit-satyam.github.io/plasmoRUtils/reference/getpairedOrthologs.md)
  : Fetch paired orthologs
- [`getPreconfiguredTable()`](https://rohit-satyam.github.io/plasmoRUtils/reference/getPreconfiguredTable.md)
  : Get pre-configured tables
- [`getPreconfiguredTableOrthomcl()`](https://rohit-satyam.github.io/plasmoRUtils/reference/getPreconfiguredTableOrthomcl.md)
  : Get pre-configured tables from OrthoMCL-DB
- [`getTable()`](https://rohit-satyam.github.io/plasmoRUtils/reference/getTable.md)
  : Get tables with custom fields
- [`listipdb()`](https://rohit-satyam.github.io/plasmoRUtils/reference/listipdb.md)
  : List species metadata present in InparanoiDB 9
- [`listMCA()`](https://rohit-satyam.github.io/plasmoRUtils/reference/listMCA.md)
  : List data sets in MCA
- [`listOrthomcl()`](https://rohit-satyam.github.io/plasmoRUtils/reference/listOrthomcl.md)
  : List species metadata present in OrthoMCL
- [`listVeupathdb()`](https://rohit-satyam.github.io/plasmoRUtils/reference/listVeupathdb.md)
  : List genomes and metadata in VEuPathDB
