# List species metadata present in InparanoiDB 9

A convenience function to quickly fetch table of all InParanoiDB 9
species and their taxonomy id.

## Usage

``` r
listipdb()
```

## Value

A data frame containing information about species present in
InParanoiDB9 and their taxon ID.

## Examples

``` r
if (FALSE) { # \dontrun{
listipdb()
} # }
```
